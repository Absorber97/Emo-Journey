🧠 Project Requirements

Your project must:

✅ Be based on one or more of the following data structures:

    Arrays

    Linked Lists

    Stacks & Queues

    Trees (e.g., Binary Trees, Heaps, Tries)

    Hash Tables

✅ Include at least one algorithmic component, such as:

    Searching or sorting

    Recursion or backtracking

    Greedy or dynamic programming

    Graph traversal or shortest path

✅ Be fully implemented in Python
✅ Have meaningful input/output for users
✅ Handle edge cases and include error checking


📂 Deliverables

Each group/individual must submit:

    1. Project Proposal (1 page)

        Title and description of the problem you're solving

        Data structures and algorithms you plan to use

        Timeline and responsibilities (if in a group)

    2. Source Code (Well-commented and organized)

    3. Final Report (2–4 pages)

        Problem statement and solution

        Explanation of chosen data structures and algorithms

        Design overview (optionally include diagrams)

        Challenges encountered and how you solved them

        Time and space complexity analysis

        Sample test cases and outputs

    4. Explanation/Presentation        

        Explain what you built and why it matters

        Highlight the algorithms and data structures used
